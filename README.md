# 한국전력기술 AX 리터러시 교육 — GPT 챗봇 구축

한국전력기술 전 부서 직위자를 위한 4시간 실습형 과정이다. 총 60명을 30명씩 두 차수로 나누며, 8월 5일과 6일 모두 같은 내용을 진행한다.

**강의 사이트**: https://leeyoojinwork-pm.github.io/kepco-enc-ax-lecture/

## 운영 구조

- 1차수: 8월 5일 13:00-17:00, 30명
- 2차수: 8월 6일 13:00-17:00, 30명
- 두 차수는 교육 대상자만 다르고 커리큘럼, 난이도, 결과물이 같다.
- 차수별 결과물: 내 반복 업무를 지원하는 맞춤 GPT 1개

## 공통 4시간 커리큘럼

1. 기초 AX 리터러시 1시간
   - 왜 지금 AI를 배워야 하는가
   - 한국전력기술의 AX 흐름
   - ChatGPT 기본 화면과 안전한 사용 기준
2. 기본 업무 자동화 1시간
   - 나쁜 프롬프트로 먼저 결과 확인
   - 업무 지시서 7요소로 개선
   - 후속 대화와 검증으로 업무 초안 완성
3. 챗봇 만들기 실습 2시간
   - STEP 1 문제정의
   - STEP 2 업무 지시서
   - STEP 3 폴더정의서와 knowledge.md
   - STEP 4 맞춤 GPT 생성, 테스트, 수정

## 핵심 프레임워크

- 업무 지시서 7요소: 역할, 하는 일, 작업방식, 출력형식, 말투, 금지사항, 예외처리
- 챗봇 만들기 4단계: 문제정의, 업무 지시서, 폴더정의서, 내 GPT 완성
- 업무 선정 기준: 반복성과 규칙성이 모두 높은 업무부터 선택
- 결과 검증: 정상 질문 2개와 일부러 모를 질문 1개로 테스트

## 운영 원칙

- 첫 1시간은 계정이 없거나 처음 사용하는 참가자도 따라올 수 있게 공통 기초로 진행한다.
- 이후 실습은 초중급 난이도로 진행하며 보조강사가 기본 팔로업을 맡는다.
- 빠르게 따라오는 참가자는 실제 부서 업무에 가까운 결과물까지 다듬는다.
- 실습에는 공개 정보와 일반화한 업무 상황만 사용한다.
- AI 결과물은 초안으로 취급하고 담당자가 사실, 보안, 표현을 확인한다.

기존의 2일 연계형 자료는 `codex/archive-two-day-linked-v1` 브랜치에 보관되어 있다.
