## 커리큘럼 설계

### 1일차 — GPT 챗봇 구축 (4h)
1부 생성형 AI 기초 (50분) → 2부 챗봇 구축 이해 (40분) → 3부 내 업무 챗봇 만들기 STEP 1~4 (95분) → 4부 공유와 클로징 (35분)

### 2일차 — 챗봇 고도화 (4h)
복습·아이스브레이커 (15분) → 5부 챗봇 고도화 이해: 지식파일·대화 시작 문구·멀티턴·확장 지도 (60분) → 6부 두 번째 챗봇: 예시 없이 4단계 완주 (90분) → 7부 배포와 정착 루프·최종 발표 (55분)

### 핵심 프레임워크
- **업무 지시서 7요소** — 프롬프트를 "신입에게 일 시키기"로 번역한 시그니처 프레임
- **4단계 절차** — 문제정의 → 업무 지시서 → 폴더정의서 → 첫 시스템 (재사용 가능한 표준 절차)
- **반복성×규칙성 매트릭스** — 챗봇에 맡길 업무를 고르는 기준 (STEP 1)
- **폴더정의서 3칸** — 챗봇에 줄 자료를 보안 기준으로 거르는 원본 구성 (STEP 3)
- **답변 진단 3갈래** — 질문/지시문/지식파일로 원인을 짚는 2일차 관통 축
- **배포 3종 세트 + 개선 루프** — 만든 챗봇이 한 달 뒤에도 살아있게 하는 정착 절차

## 제작 배경 (자료조사 요약)

- **청중**: 원자력·화력 발전소 설계 공기업, 5개 본부 전 부서 직위자. 부서별 예시를 실제 본부 구조(설계·기술/사업관리/경영관리/전략기획)로 매핑.
- **후킹 팩트**: NEXA/NEXA 2.5 등 사내 생성형 AI 흐름, AI혁신대상 2년 연속 그랑프리(2025·2026), SK AX와 AX MOU(2026.07) — "회사는 이미 AX를 추진 중, 오늘은 내 책상 차례".
- **통계**: 직장인 74.3% 주1회+ AI 사용, 75.8% 효율 향상(나우앤서베이 2026), AI 사용자 주당 평균 1.5시간 단축(한국은행 분석).
- **보안**: 국정원 생성형 AI 가이드라인 — 비공개·개인정보 입력 금지, 결과물 재검증. 실습 소재는 ALIO 공시·보도자료 등 공개 데이터.
- **교육 설계 벤치마킹**: 공기업 1,250명 교육 사례(만족도 4.7/5)의 성공 요인 — 실제 데이터 실습, 직군별 세분화, 누적 구조(앞 실습 산출물이 뒷 실습 입력), "만들었다"는 경험.
- **GPTs 스펙(2026.08.01 공식 문서 기준)**: 지식파일 GPT당 20개·파일당 512MB, hwp 인식 불가(txt 변환), 제작·편집은 유료 계정/권한 필요, 사용은 로그인한 사용자 기준.
